# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment trends in India using Python and data visualization techniques. The analysis focuses on unemployment rates across different regions and months and examines changes during the COVID-19 period.

## Objectives

- Analyze unemployment trends in India.
- Compare unemployment rates across different regions.
- Study monthly unemployment patterns.
- Analyze seasonal variations in unemployment.
- Examine unemployment trends before and during COVID-19.
- Visualize the results using graphs and charts.

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV Dataset
- Jupyter Notebook / VS Code

## Dataset

The project uses an unemployment dataset containing information such as:

- Region
- Date
- Frequency
- Estimated Unemployment Rate
- Estimated Employed
- Estimated Labour Participation Rate
- Area type

## Analysis Performed

The project includes analysis of:

1. Unemployment rate over time
2. Average unemployment by region
3. Average unemployment by month
4. Seasonal unemployment patterns
5. Unemployment rate before and during COVID-19

## Visualizations

The project generates visualizations to make the unemployment trends easier to understand.

The generated charts include:

- Unemployment Rate Over Time
- Average Unemployment by Region
- Average Unemployment by Month
- Seasonal Unemployment by Month
- Unemployment Rate Before vs During COVID-19

## Project Files

- `unemployment_analysis.py` – Python analysis script
- `unemployment in india.csv` – Dataset
- `average_unemployment_by_region.png` – Regional analysis
- `average_Unemployment_by_month.png` – Monthly analysis
- `seasonal_unemployment_by_month.png` – Seasonal analysis
- `unemployment_rate_over_time.png` – Time-series analysis
- `unemployment_rate_before_vs_during_covid...png` – COVID-19 comparison

## Conclusion

This project provides a visual analysis of unemployment trends in India and highlights variations across regions, months, seasons, and the COVID-19 period.
