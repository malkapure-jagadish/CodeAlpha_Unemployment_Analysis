# CodeAlpha Unemployment Analysis

## Project Overview
This project analyzes unemployment trends in India using Python, Pandas, and Matplotlib. It explores unemployment rates over time, compares unemployment before and during the COVID-19 period, and analyzes differences across regions.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV Dataset

## Project Files
- `unemployment_analysis.py` – Python analysis script
- `unemployment in india.csv` – Dataset
- `unemployment_rate_over_time.png` – Unemployment trend visualization
- `unemployment_rate_before_vs_during_covid19.png` – COVID-19 comparison chart
- `average_unemployment_by_region.png` – Regional unemployment chart

## Key Insights
- Unemployment rates increased significantly during the COVID-19 period.
- The average unemployment rate before COVID-19 was approximately 8.09%.
- The average unemployment rate during COVID-19 was approximately 16.18%.
- Unemployment rates varied across different regions.

## Conclusion
This project demonstrates how Python and data visualization can be used to analyze unemployment trends and understand the impact of COVID-19 on unemployment rates in India.
